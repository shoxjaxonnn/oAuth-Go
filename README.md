# oAuth Demo (Go backend)

Same authentication demo as [oAuth](https://github.com/shoxjaxonnn/oAuth), with the backend rewritten in **Go** instead of Node.js — same 4 sign-in methods (Google, Facebook, Telegram OTP, Firebase email/password), same security model (access + rotating refresh tokens, rate limiting, account linking, user-enumeration protection).

**Frontend:** React + TypeScript + Vite (unchanged)
**Backend:** Go (in progress)
